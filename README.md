Outils internes de La Framboise Digitale.

| Dossier | Contenu | En ligne |

## Important
- Les **données** (projets, clients, devis…) sont stockées dans la base de chaque page sur claude.ai,
  pas dans ce dépôt. Republier une nouvelle version du code à la même adresse garde toutes les données.
- Aucune clé API ni mot de passe ne doit être ajouté dans ce dépôt.

## Branches
- `main` : les versions actuellement en ligne.
- `corrections-voix-off` : Social Studio avec les corrections de la voix off (non testées, non publiées).
